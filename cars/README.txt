MOSES BENZ AUTO CARE — CAR FILES
================================

Each vehicle has its own folder:

cars/<car-name>/<car-name>.html
cars/<car-name>/<car-name>.jpg

Replace the .jpg file with your own vehicle photograph, keeping the exact
filename. Do not use online image URLs for vehicle photos.

The HTML file is the vehicle's own detail page. The catalogue metadata is
kept in js/cars.js. If you add a completely new vehicle, add its record there
and create its matching folder/page/image.

The Admin Portal controls whether an existing vehicle is shown or hidden.
