Moses Benz Auto Care vehicle image library

All catalogue vehicle images are intentionally stored flat in this folder:
  /cars/<vehicle-slug>.jpg

The public catalogue does not categorize vehicle images into A-Class, C-Class,
E-Class, SUV folders, or other class directories. Vehicle grouping/filtering is
handled by the inventory interface, so the asset library stays simple and easy
to maintain.


IMAGE UPDATE
The vehicle images are flat files named to match the catalogue slug. The new sample images intentionally contain no model/year caption text; the vehicle identity is supplied by the website card/detail caption. A generic vehicle-placeholder.jpg is retained as a fallback.
