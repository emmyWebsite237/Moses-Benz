Workshop control centre. Manage the catalogue, customer requests, inventory and repair media from one place. Supabase is the shared source of truth for workshop content. Changes made here are intended to be visible across devices.
Overview

Workshop dashboard

Use the directory buttons above to jump into each part of the portal.

Appointments

Review incoming requests, set the appointment time yourself, and contact the customer directly.

Blog

Publish useful automotive articles and remove posts you no longer want online.

Inventory

Manage which GitHub-hosted Mercedes-Benz vehicles are visible on the public inventory.

Customer Requests

Appointment requests

Set or adjust the actual date and time yourself. Once a visit is Done or Cancelled, you can delete it. Contact the customer directly by phone or WhatsApp.

Vehicles

Inventory

Vehicle pages and photographs live in the GitHub /cars folders. This portal only controls whether an existing vehicle is visible in the public inventory.

Vehicle visibility

To add a new vehicle, add its folder, HTML page and JPG image to /cars, then add its catalogue record to js/cars.js. After deployment it will appear here.

Repair Stories

Before & After

One gallery per repair: Before → Process → After. Add as many process images as needed with the + button. Customers can swipe, use arrows or watch the gallery advance automatically.
